Xcompute 的模型列表会随账号权限和服务配置变化。下面是当前已配置的模型分类。调用前请使用 `GET /v1/models`，或打开[模型广场](https://xcompute.us/models)，确认你的 API Key 可以看到目标模型。

## 如何查看你能用的模型

```bash
curl --request GET \
  --url https://xcompute.us/v1/models \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

返回中的每个 `id` 就是可以填入请求体 `model` 字段的模型 ID。不同账号看到的列表可能不同；模型目录下的分类不能替代接口返回结果。

## 模型可见性

模型是否可调用取决于以下因素：

- API Key 的账号权限和可用额度
- 模型当前是否启用
- 模型是否属于你的账号方案
- 该模型是否有可用服务线路

如果模型不在 `GET /v1/models` 返回结果中，不要直接猜测模型名。遇到 `model_not_found` 或 `No available channel` 时，请从接口返回列表中选择模型，或联系管理员确认权限。

## 价格

文本模型通常按 Token 计费，图片模型通常按次计费。具体价格以[模型定价](https://xcompute.us/pricing)页面和你的账号实际显示为准。
