title: 'GPT Image 2 同步图像生成'
description: '使用 XCompute 国际站的 gpt-image-2 模型同步生成 1K、2K 或 4K 图片。'
api: 'POST /v1/images/generations'
---

`gpt-image-2` 使用 OpenAI Images 兼容协议。请求会保持连接，图片生成完成后直接返回图片 URL 或内联 Base64 数据。

## 价格

| 分辨率 | 推荐 `size` | 单张价格 |
| --- | --- | --- |
| 1K | `1024x1024` | $0.03 |
| 2K | `2048x2048` | $0.045 |
| 4K | `4096x4096` | $0.045 |

<Note>
  价格按请求分辨率档位计算。失败请求会按平台计费规则退款。
</Note>

  ```bash cURL theme={null}
      "size": "2048x2048",

      "n": 1,
      "response_format": "url"

  ```

## 请求参数

<ParamField header="Authorization" type="string" required>
  使用 Bearer Token 认证，例如 `Authorization: Bearer YOUR_API_KEY`。你可以在 [API Key 管理页面](https://xcompute.us/keys) 创建密钥。
</ParamField>

<ParamField body="model" type="string" default="gpt-image-2" required>
  固定填写 `gpt-image-2`。
</ParamField>

<ParamField body="prompt" type="string" required>
  图片内容描述。支持中文和英文。
</ParamField>

<ParamField body="size" type="string" default="1024x1024">
  输出尺寸。正方形常用值为 `1024x1024`、`2048x2048` 和 `4096x4096`。

  也可以传入其他宽高组合。最长边不超过 1920 像素时按 1K 档计费；最长边超过 1920 像素时按 2K/4K 档计费。
</ParamField>

<ParamField body="quality" type="string" default="auto">
  图片质量。可选值：`auto`、`low`、`medium`、`high`。

  `quality` 控制生成质量，不决定分辨率档位。分辨率由 `size` 决定。
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量。支持 `1` 到 `4`。
</ParamField>

<ParamField body="response_format" type="string" default="url">
  建议填写 `url`。根据上游结果，`data[0].url` 可能是公网 URL，也可能是以 `data:image/png;base64,` 开头的内联图片。
</ParamField>

## 成功响应

<ResponseExample>
  ```json 200 theme={null}
  {
    "created": 1785780998,
    "model": "gpt-image-2",
    "data": [
      {
        "url": "https://example.com/generated-image.png"
      }
    ],
    "usage": {
      "total_tokens": 3591
    }
  }
  ```
</ResponseExample>

从 `data[0].url` 读取图片。如果该值是 Data URL，可以直接赋给浏览器 `<img>` 的 `src`，也可以解码 Base64 后保存为 PNG。

## 图像编辑

带参考图的请求使用 `POST /v1/images/edits`。模型仍填写 `gpt-image-2`。参考图需要是 XCompute 能访问的 HTTP 或 HTTPS URL。

```bash cURL theme={null}
curl --request POST \
  --url https://xcompute.us/v1/images/edits \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "gpt-image-2",
    "prompt": "把主体改成水彩画风格",
    "images": ["https://example.com/reference.png"],
    "size": "2048x2048",
    "quality": "medium"
  }'
```

## 注意事项

- 同步请求通常需要几十秒。客户端超时建议设置为至少 300 秒。
- 1K、2K 和 4K 已在 XCompute 国际站完成实际请求验证。
- `quality=auto`、`low`、`medium`、`high` 均受支持。
- 如果你的业务不能保持长连接，请使用 [GPT Image 2 异步图像生成](/api-reference/images/gpt-image-2/async-generation)。
