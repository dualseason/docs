api: 'POST /v1/images/generations'
---

使用 `gpt-image-2.5` 调用同步图像生成接口。请求会保持 HTTP 连接，直到图片生成完成并返回结果。客户端超时建议设置为至少 300 秒。

## 请求示例

<RequestExample>
  ```bash cURL theme={null}
  curl --request POST \
    --url https://xcompute.us/v1/images/generations \
    --header 'Authorization: Bearer YOUR_API_KEY' \
    --header 'Content-Type: application/json' \
    --data '{
      "model": "gpt-image-2.5",
      "prompt": "一只橘猫坐在窗台上看夕阳，水彩插画风格",
      "size": "1536x1024",
      "quality": "medium",
      "n": 1,
      "response_format": "url"
    }'
  ```

  ```python Python theme={null}
  import requests

  response = requests.post(
      "https://xcompute.us/v1/images/generations",
      headers={
          "Authorization": "Bearer YOUR_API_KEY",
          "Content-Type": "application/json",
      },
      json={
          "model": "gpt-image-2.5",
          "prompt": "一只橘猫坐在窗台上看夕阳，水彩插画风格",
          "size": "1536x1024",
          "quality": "medium",
          "n": 1,
          "response_format": "url",
      },
      timeout=300,
  )
  response.raise_for_status()

  print(response.json()["data"][0]["url"])
  ```

  ```javascript JavaScript theme={null}
  const response = await fetch("https://xcompute.us/v1/images/generations", {
    method: "POST",
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "gpt-image-2.5",
      prompt: "一只橘猫坐在窗台上看夕阳，水彩插画风格",
      size: "1536x1024",
      quality: "medium",
      n: 1,
      response_format: "url",
    }),
  });

  if (!response.ok) throw new Error(await response.text());
  console.log((await response.json()).data[0].url);
  ```
</RequestExample>

## 请求参数

<ParamField header="Authorization" type="string" required>
  Bearer Token，例如 `Authorization: Bearer YOUR_API_KEY`。你可以在 [API Key 管理页面](https://xcompute.us/keys) 创建密钥。
</ParamField>

<ParamField body="model" type="string" default="gpt-image-2.5" required>
  固定填写 `gpt-image-2.5`。
</ParamField>

<ParamField body="prompt" type="string" required>
  图片内容描述。支持中文和英文。建议清晰描述主体、环境、构图和风格。
</ParamField>

<ParamField body="size" type="string" default="1024x1024">
  输出尺寸必须使用下方列出的支持值。
</ParamField>

<ParamField body="quality" type="string" default="auto">
  图片质量。可选值为 `auto`、`low`、`medium`、`high`。
</ParamField>

<ParamField body="n" type="integer" default="1">
  生成数量。
</ParamField>

<ParamField body="response_format" type="string" default="url">
  返回格式。建议填写 `url`。
</ParamField>

## 支持尺寸

`size` 仅支持以下尺寸：

| 档位 | 支持的 `size` |
| --- | --- |
| 标准 | `1024x1024`、`1536x1024`、`1024x1536`、`1024x1365`、`1365x1024`、`1088x1920`、`1920x1088` |
| 高分辨率 | `2048x2048`、`1712x2560`、`2560x1712`、`2048x1536`、`1152x2048`、`2048x1152`、`2880x2880`、`2560x3840`、`3840x2560`、`3840x2880`、`2160x3840`、`3840x2160` |

## 成功响应

<ResponseExample>
  ```json 200 theme={null}

    "created": 1789097054,

      {

        "revised_prompt": "一只橘猫坐在窗台上看夕阳，水彩插画风格"

      "input_tokens": 18,
  ```

从 `data[0].url` 读取生成图片。图片 URL 可能具有有效期，请及时下载并保存到自己的存储服务。

## 注意事项

- 同步请求通常需要几十秒，客户端超时建议至少为 300 秒。
- 图片尺寸必须使用本文列出的值。
- 生产环境应检查 HTTP 状态码，并在图片生成完成后及时转存。
- 不能保持长连接的业务请使用 [GPT Image 2.5 异步图像生成](/api-reference/images/gpt-image-2/async-generation)。
