## 1. 安装并打开桌面端

从 [OpenCode 官方下载页面](https://opencode.ai/download)安装桌面端，打开一个项目文件夹。

第一次使用时，先选择 OpenCode 当前提供的免费 AI，发送：

```text
请先分析这个项目的目录结构和启动方式，不要修改任何文件。
```

## 2. 添加 Xcompute

在 Provider、Model Provider 或设置页面添加 OpenAI 兼容服务：

- Name：`Xcompute`
- Base URL：`https://xcompute.us/v1`
- API Key：在 [控制台](https://xcompute.us/keys)创建后填写
- Model list：点击“同步模型”或“刷新模型列表”
- Context length：`1000000`

如果桌面端自带 AI 可以执行设置操作，也可以发送：

```text
请添加 Xcompute OpenAI 兼容 Provider。
Base URL 是 https://xcompute.us/v1，请调用 GET /models 获取全部模型，不要手工填写模型名。
上下文长度设置为 1000000。API Key 我会在设置界面填写，不要读取或输出它。
保存前展示 Provider、模型列表和上下文设置，等待确认。
```

## 3. 选择模型

配置完成后，从模型选择器中选择 Xcompute 模型。模型列表以 `GET /v1/models` 返回结果为准，不要照抄旧教程中的模型名。

简单任务优先使用免费 AI 或成本较低的模型；复杂重构、长上下文和多文件任务再使用能力更强的 Xcompute 模型。

## 4. 安全和成本

- API Key 只填写在客户端的密钥字段，不要粘贴到对话框。
- 不要让 AI 把 API Key 写入项目、提交到 Git 或输出到日志。
- 先让 AI 说明计划，再执行修改。
- 只打开相关目录，减少无关上下文和 Token 消耗。
