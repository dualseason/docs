## 1. 安装并打开桌面端

从 [OpenCode 官方下载页面](https://opencode.ai/download)安装桌面端，打开一个项目文件夹。

第一次使用时，先选择 OpenCode 当前提供的免费 AI，发送：

```text
请使用下面的连接信息配置 Xcompute OpenAI 兼容 Provider：
- Provider：Xcompute
- Base URL：{{XCOMPUTE_BASE_URL}}
- API Key：{{XCOMPUTE_API_KEY}}
- Models endpoint：{{XCOMPUTE_MODELS_ENDPOINT}}
- Context length：{{XCOMPUTE_CONTEXT_LENGTH}}

请通过 Models endpoint 自动读取模型，不要手工猜测模型名。{{XCOMPUTE_API_KEY}} 只表示客户端安全密钥字段，真实 Key 由我从 API 密钥管理页面复制后直接填写，不要在聊天记录、项目文件或日志中保存。
配置完成后先展示 Provider、请求地址、模型列表和上下文设置，等待我确认后再保存。
```

## 2. 添加 Xcompute

在 Provider、Model Provider 或设置页面添加 OpenAI 兼容服务：

- Name：`Xcompute`
- Base URL：`https://xcompute.us/v1`
- 连接信息：打开 [API 密钥管理页面](https://xcompute.us/keys)，点击“使用令牌”获取；API Key 粘贴到客户端的安全字段
- Model list：点击“同步模型”或“刷新模型列表”
- Context length：`1000000`

如果桌面端自带 AI 可以执行设置操作，也可以发送：

```text
请添加 Xcompute OpenAI 兼容 Provider。
Base URL 是 https://xcompute.us/v1，请调用 GET /models 获取全部模型，不要手工填写模型名。
上下文长度设置为 1000000。请提示我打开 API 密钥管理页面获取连接信息，并将 API Key 直接填入客户端安全字段，不要把真实 Key 写入对话、项目或日志。
保存前展示 Provider、模型列表和上下文设置，等待确认。
```

## 3. 选择模型

配置完成后，从模型选择器中选择 Xcompute 模型。模型列表以 `GET /v1/models` 返回结果为准，不要照抄旧教程中的模型名。

简单任务优先使用免费 AI 或成本较低的模型；复杂重构、长上下文和多文件任务再使用能力更强的 Xcompute 模型。

## 4. 安全和成本

- 先到 [API 密钥管理页面](https://xcompute.us/keys)获取连接信息，再将 API Key 直接填写到客户端安全字段。
- 不要让 AI 把 API Key 写入项目、提交到 Git 或输出到日志。
- 先让 AI 说明计划，再执行修改。
- 只打开相关目录，减少无关上下文和 Token 消耗。
