## 1. 先使用免费 AI

从 WorkBuddy 官方渠道安装桌面端，登录后直接选择一个官方自带的免费 AI。它适合问答、摘要、改写、邮件、表格和资料整理。

免费 AI 的具体模型、额度和质量由 WorkBuddy 当前版本、地区和账号决定，以应用内显示为准；不要把免费能力理解为固定模型或永久额度。

## 2. 接入 Xcompute

如果当前版本提供自定义 Provider、OpenAI 兼容或 API 设置，填写：

- Provider：`Xcompute`
- Base URL：`https://xcompute.us/v1`
- 连接信息：打开 [API 密钥管理页面](https://xcompute.us/keys)，点击“使用令牌”获取；API Key 粘贴到客户端安全字段
- Models：点击“获取模型”“同步模型”或“刷新模型列表”
- Context length：`1000000`

也可以让 WorkBuddy 的免费 AI 协助配置：

```text
请使用下面的连接信息配置 Xcompute OpenAI 兼容 Provider：
- Provider：Xcompute
- Base URL：{{XCOMPUTE_BASE_URL}}
- API Key：{{XCOMPUTE_API_KEY}}
- Models endpoint：{{XCOMPUTE_MODELS_ENDPOINT}}
- Context length：{{XCOMPUTE_CONTEXT_LENGTH}}

请通过 Models endpoint 自动读取模型，不要手工猜测模型名。{{XCOMPUTE_API_KEY}} 只表示客户端安全密钥字段，真实 Key 由我从 API 密钥管理页面复制后直接填写，不要在聊天记录、项目文件或日志中保存。
配置完成后先展示 Provider、请求地址、模型列表和上下文设置，等待我确认后再保存。
```

如果当前 WorkBuddy 版本没有自定义 Provider 功能，就继续使用自带 AI，或使用 [OpenCode 桌面端](/opencode-install)接入 Xcompute。

## 3. 合理使用

- 简单摘要、改写和问答优先用免费 AI。
- 长文档、复杂分析和指定模型再切换 Xcompute。
- 不要重复上传相同文件或完整历史记录。
- 涉及删除、发送或修改重要资料时，先让 AI 给方案并确认。
