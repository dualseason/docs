不需要先理解模型或 API，只看任务类型：

| 任务 | 工具 | 入口 |
| --- | --- | --- |
| 邮件、文档、表格、资料整理 | WorkBuddy | [WorkBuddy 入门](/workbuddy) |
| 修改网站、程序和项目代码 | OpenCode | [OpenCode 配置](/opencode-install) |
| 已购买 Codex 官方订阅 | Codex | [Codex 协作](/codex-cli-app) |

## 选择原则

- 日常内容使用 WorkBuddy，不需要配置 Xcompute API Key。
- 代码任务使用 OpenCode，配置 Xcompute API Key 后即可调用模型。
- 有 Codex 订阅时继续使用订阅，不需要把 Xcompute API Key 配进 Codex。

同一个项目可以被多个工具打开，但不要让两个工具同时修改同一个文件。
