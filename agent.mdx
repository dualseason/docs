你不需要先理解模型、API 或命令行。只要先判断自己要做的是日常工作还是修改代码，再选择对应工具。

<Tip>
  **最简单的选择**

  日常工作使用 WorkBuddy；修改代码使用 OpenCode；已经有 Codex 订阅的用户保留 Codex 订阅，把项目文件夹交给 OpenCode 或 WorkBuddy 打开。
</Tip>

## 三种情况

### 日常任务：WorkBuddy

适合写邮件、总结资料、整理表格和处理办公内容。直接使用桌面端，用中文描述任务即可。

### 代码任务：OpenCode

适合打开网站或程序项目、修改代码、运行测试和查看改动。请从 [OpenCode 安装与配置](/opencode-install) 开始。

### 已有 Codex 订阅：保留订阅

Codex 订阅适合已经购买官方订阅并希望继续使用订阅额度的客户。订阅和 Xcompute API 不需要同时配置在 Codex 里。

推荐做法：

1. 在 Codex 官方 App 或 CLI 中登录订阅账号。
2. 用 Codex、OpenCode 或 WorkBuddy 打开同一个项目文件夹，但不要同时修改同一文件。
3. 需要通过 Xcompute 使用模型时，再按照 [OpenCode 配置教程](/opencode-install) 配置 OpenCode。

## 快速对比

| 特性 | WorkBuddy | Codex | OpenCode |
| --- | --- | --- | --- |
| 主要用途 | 日常工作 | 已有订阅的代码任务 | Xcompute 代码任务 |
| 上手方式 | 桌面端点击使用 | 官方 App 或 CLI | OpenCode 桌面端或 CLI |
| 是否需要 Xcompute API Key | 视具体配置 | 使用订阅时不需要 | 需要 |
| 是否适合修改代码 | 不优先 | 适合 | 推荐 |
