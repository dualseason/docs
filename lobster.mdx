---
title: "龙虾配置"
description: "在龙虾客户端中使用免费 AI 或配置 Xcompute。"
---

龙虾的菜单名称和 Provider 支持以当前版本为准。先选择客户端自带的免费 AI，确认基础功能正常，再添加 Xcompute。

## Xcompute 参数

- 协议：`OpenAI Compatible`
- Base URL：`https://xcompute.us/v1`
- 连接信息：打开 [API 密钥管理页面](https://xcompute.us/keys)，点击“使用令牌”获取；API Key 粘贴到客户端安全字段
- 模型：通过 `GET /v1/models` 获取，不要手工猜测
- 上下文长度：`1000000`

如果龙虾支持 AI 自动配置，可以发送：

```text
请添加 Xcompute OpenAI 兼容 Provider。
Base URL 是 https://xcompute.us/v1，通过 GET /models 获取全部模型，Context length 设置为 1000000。
请提示我打开 API 密钥管理页面获取连接信息，并将 API Key 直接填入客户端安全字段，不要把真实 Key 写入对话、项目或日志。保存前等待确认。
```

免费 AI 适合简单任务；复杂任务再使用 Xcompute。配置失败时，先确认客户端是否支持 OpenAI 兼容 Provider，再检查 Base URL 是否包含 `/v1`。
