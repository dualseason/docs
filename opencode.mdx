OpenCode 适合打开项目、阅读代码、修改文件、运行命令和检查测试结果。

## 两种使用方式

| 方式 | 适合场景 | 成本 |
| --- | --- | --- |
| OpenCode 官方内置 AI | 了解工具、简单问答、小范围修改 | 以 OpenCode 官方当前方案和账号额度为准 |
| Xcompute 中转模型 | 长上下文、复杂重构、多文件任务、需要更多模型选择 | 按 Xcompute 实际用量计费 |

OpenCode 的官方免费能力、可用模型和额度会随版本、地区、登录状态和官方政策变化。它适合入门和低风险任务，但不应把“免费”理解为固定模型、固定额度或永久可用。

Xcompute 提供多种文本模型，通过兼容接口接入 OpenCode。具体模型和分组以[模型目录](/xcompute-models)及模型广场实时显示为准。

## 能力怎么选

### 官方免费 AI

适合：

- 询问项目结构和启动方法
- 解释一段代码
- 生成小段示例代码
- 修改单个文件并检查格式

这类任务通常不需要最高级模型，优先使用官方免费能力即可。

### Xcompute 中转模型

适合：

- 同时修改多个文件
- 复杂重构和迁移
- 长上下文项目分析
- 需要特定模型或更稳定吞吐
- 需要图像、文本等统一 API 接入

中转模型不代表所有任务都更好。先从便宜、能力足够的模型开始，遇到上下文、推理或代码质量问题，再升级模型。

## 配置 Xcompute

需要使用 Xcompute 时，按照[OpenCode 安装与配置](/opencode-install)完成配置：

- Base URL：`https://xcompute.us/v1`
- API Key：[在控制台创建](https://xcompute.us/keys)
- Model ID：从[模型目录](/xcompute-models)复制

配置后，OpenCode 的官方 AI 和 Xcompute 模型可以按任务分别使用。不要把 API Key 提交到项目仓库或发送给他人。

## 推荐工作流

1. 先用免费 AI 分析任务和项目结构。
2. 把需求拆成小步骤，先让工具说明计划。
3. 简单修改继续使用免费 AI。
4. 复杂重构、长上下文或质量要求高的任务再切换 Xcompute。
5. 每一步都查看 diff 并运行测试，不要一次性生成大段无用代码。

需要安装 OpenCode 的完整步骤，请看[客户端配置](/opencode-install)。
