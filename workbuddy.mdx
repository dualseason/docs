WorkBuddy 适合处理不需要修改代码的日常任务。你可以直接用中文描述需求，让它帮你整理资料、写邮件、总结文档、处理表格或生成日常内容。

## 先记住怎么选

| 你要做的事 | 推荐工具 |
| --- | --- |
| 写邮件、总结资料、整理表格、生成日常文案 | WorkBuddy |
| 修改网站、程序或项目代码 | OpenCode |
| 已经购买 Codex 订阅并想继续使用 | Codex 登录订阅；项目文件用 OpenCode 或 WorkBuddy 打开 |

<Tip>
  不确定是不是代码任务时，先用 WorkBuddy 描述需求。它判断需要修改程序时，再按照 [OpenCode 代码任务教程](/opencode-install) 操作。
</Tip>

## 第一步：安装并打开 WorkBuddy

请从 WorkBuddy 官方渠道下载安装包。安装完成后，像打开普通软件一样双击 WorkBuddy 图标。

第一次打开时，按照界面提示登录或完成授权。不要把 Xcompute API Key 粘贴到聊天窗口，也不要发给客服或其他人。

## 第二步：先做一个简单任务

在输入框粘贴下面这句话，然后点击发送：

```text
请告诉我你能帮我完成哪些日常工作，并列出三个具体例子。
```

看到正常回复后，再输入你的真实需求。第一次不要直接让它处理一整批重要文件，先用一份复制品测试。

## 第三步：学会描述需求

每次任务尽量说清楚四件事：

1. 你现在有什么材料，例如一份 Word、Excel 或几段文字。
2. 你希望得到什么结果。
3. 结果要使用什么格式，例如表格、邮件或 Markdown。
4. 哪些内容不能改动，或者需要你确认后才能执行。

可以直接套用这个模板：

```text
我有：一份客户反馈表。
请做：按问题类型分类，并统计每类数量。
输出：生成一个新的 Excel 表格，并先告诉我你准备怎么处理。
限制：不要修改原始文件，不要删除任何数据。
```

## 常见日常任务

- 总结 Word、PDF 或网页内容
- 把会议记录整理成待办清单
- 根据要点写邮件、通知和工作汇报
- 清理和分类文件名
- 统计 Excel 表格并生成摘要
- 把一段口语改写成正式表达

涉及删除文件、发送邮件、提交订单或修改重要表格时，明确要求它先展示方案，等你确认后再执行。

## 与 OpenCode 共用项目文件夹

项目文件夹就是保存网站或程序文件的文件夹。OpenCode 和 WorkBuddy 可以先后打开同一个文件夹，但不要让两个工具同时修改同一个文件。

推荐顺序：

1. 用 WorkBuddy 说明需求、整理素材或写功能清单。
2. 用 OpenCode 打开项目文件夹并修改代码。
3. 回到 WorkBuddy 检查说明文字、整理测试结果或生成发布内容。

不要把 API Key、密码、数据库备份等敏感文件放进要上传或分享的项目文件夹。

## 有 Codex 订阅时怎么用

Codex 订阅和 Xcompute API Key 是两种不同的计费方式：

- Codex 订阅：在 Codex 官方 App 或 CLI 中登录你的订阅账号。
- Xcompute API：在 OpenCode 或 WorkBuddy 的配置中填写 Xcompute API Key。

有 Codex 订阅时，建议继续在 Codex 中使用订阅额度，不要为了打开同一个项目而重复购买 API。需要在国内网络环境下操作项目时，可以关闭 Codex，然后用 OpenCode 或 WorkBuddy 打开相同的项目文件夹。
