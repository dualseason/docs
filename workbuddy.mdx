WorkBuddy 适合写邮件、总结资料、整理会议记录、处理表格和生成日常内容。

## 自带 AI 与 Xcompute

| 方式 | 建议用途 |
| --- | --- |
| WorkBuddy 自带免费 AI | 问答、摘要、改写、简单表格和日常文案 |
| Xcompute 中转模型 | 长文档、多轮处理、复杂分析或需要指定模型 |

自带 AI 的具体模型、额度和免费政策由 WorkBuddy 当前版本和账号决定，以应用内显示为准。简单任务优先使用自带 AI；只有在任务确实需要更强能力或指定模型时，才切换 Xcompute。

## 开始使用

1. 从 WorkBuddy 官方渠道下载安装并打开应用。
2. 按界面提示登录或授权。
3. 先用一份非关键文件测试，再处理正式材料。

可以这样描述任务：

```text
我有：一份客户反馈表。
请做：按问题类型分类并统计数量。
输出：生成一个新的 Excel 文件。
限制：不要修改原始文件，先告诉我处理方案。
```

## 接入 Xcompute

如果当前 WorkBuddy 版本支持自定义 OpenAI 兼容接口，填写：

- Base URL：`https://xcompute.us/v1`
- API Key：[在控制台创建](https://xcompute.us/keys)
- Model ID：从[模型目录](/xcompute-models)复制文本模型 ID

不同版本的配置名称可能不同，请以 WorkBuddy 实际界面为准。看不到自定义接口选项时，继续使用自带 AI，或改用[OpenCode](/opencode)配置 Xcompute。

## 适合的任务

- 总结 Word、PDF、网页或会议记录
- 写邮件、通知和工作汇报
- 清理文件名和分类资料
- 统计 Excel 并生成摘要

删除文件、发送邮件或修改重要数据时，要求 AI 先展示方案，确认后再执行。

## 降低 Token 消耗

- 简单改写和摘要优先使用自带免费 AI。
- 只上传与任务有关的资料，不要重复发送完整历史。
- 先要求输出计划，再决定是否执行复杂处理。
- 把大任务拆成小任务，完成一步后检查结果。
