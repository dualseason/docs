Hermes 的具体设置名称会随版本变化。先选择 Hermes 自带的免费 AI，确认客户端可用，再添加自定义 Provider。

## Xcompute 参数

- 协议：`OpenAI Compatible`
- Base URL：`https://xcompute.us/v1`
- 连接信息：打开 [API 密钥管理页面](https://xcompute.us/keys)，点击“使用令牌”获取；API Key 粘贴到客户端安全字段
- 模型：通过 `GET /v1/models` 自动同步
- 上下文长度：`1000000`

可以让 Hermes 自带 AI 协助操作：

```text
请检查当前客户端是否支持 OpenAI 兼容 Provider。
如果支持，添加 Xcompute，Base URL 为 https://xcompute.us/v1，调用 GET /models 获取模型列表，
上下文长度设置为 1000000。请提示我打开 API 密钥管理页面获取连接信息，并将 API Key 直接填入客户端安全字段，不要把真实 Key 写入对话或日志，保存前等待确认。
```

简单问答和摘要优先使用免费 AI；长上下文、复杂推理和多步骤任务再使用 Xcompute。API Key 只保存在客户端的安全配置中。
