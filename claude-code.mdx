## 官方使用

Claude Code 的官方账号、订阅和网络要求由 Anthropic 决定。先按 [Claude Code 官方文档](https://docs.anthropic.com/en/docs/claude-code/overview)安装并登录，简单任务优先使用官方提供的免费或订阅能力。

## 配置 Xcompute

只有当前版本支持自定义 API 地址、Provider 或 OpenAI 兼容协议时，才添加 Xcompute：

- Base URL：`https://xcompute.us/v1`
- API Key：在 [Xcompute 控制台](https://xcompute.us/keys)创建
- Models：通过 `GET /v1/models` 自动获取
- Context length：`1000000`

可以先让 Claude Code 检查当前版本的配置方式：

```text
请检查当前 Claude Code 版本是否支持自定义兼容 API Provider。
如果支持，添加 Xcompute，Base URL 为 https://xcompute.us/v1，调用 GET /models 获取模型列表，
上下文长度设置为 1000000。API Key 由我在配置界面填写，不要读取或输出它，保存前等待确认。
```

如果版本不支持自定义 Provider，不要修改官方登录流程。使用官方 Claude Code，或改用 [OpenCode](/opencode-install)接入 Xcompute。
