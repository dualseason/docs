## 官方订阅

如果你有 Codex 官方订阅，直接在 Codex 桌面端或 CLI 登录官方账号。简单代码任务可以优先使用官方提供的免费或订阅额度，不需要重复配置 Xcompute。

## 配置 Xcompute

只有当前 Codex 版本提供自定义 Provider、OpenAI Compatible 或 Base URL 设置时，才按以下字段配置：

- Base URL：`https://xcompute.us/v1`
- API Key：在 [Xcompute 控制台](https://xcompute.us/keys)创建
- Models：请求 `GET /v1/models` 自动同步
- Context length：`1000000`

可以让 Codex 自带 AI 协助检查配置：

```text
请检查当前客户端是否支持 OpenAI 兼容 Provider。
如果支持，添加 Xcompute，Base URL 为 https://xcompute.us/v1，
通过 GET /models 获取模型列表，Context length 设置为 1000000。
API Key 不要读取、显示或写入项目文件，保存前等待确认。
```

如果当前版本不支持自定义 Provider，不要修改官方登录配置。继续使用 Codex 官方订阅，或使用 [OpenCode](/opencode-install)接入 Xcompute。

不要同时让 Codex 和其他 Agent 修改同一个文件；每次修改后检查 diff 和测试结果。
