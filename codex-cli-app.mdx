如果你已经购买 Codex 官方订阅，继续在 Codex 官方 App 或 CLI 登录订阅账号即可。不要为了使用同一个项目再把 Xcompute API Key 配进 Codex。

<Tip>
  对电脑初学者，推荐将 Codex 订阅、OpenCode 和 WorkBuddy 分工使用：Codex 保留官方订阅；OpenCode 处理代码；WorkBuddy 处理日常材料和说明文字。
</Tip>

## 先登录 Codex 订阅

1. 从 [Codex 官方页面](https://chatgpt.com/codex?app-landing-page=true) 安装或打开 Codex。
2. 使用购买订阅的 OpenAI 账号登录。
3. 按 Codex 界面提示选择或打开项目文件夹。
4. 先输入“请分析这个项目，不要修改任何文件”，确认可以正常使用。

Codex 订阅按 OpenAI 官方规则计费。Xcompute API Key 是另一种独立的计费方式，两者不需要混用。

## 如何与 OpenCode、WorkBuddy 协作

项目文件夹就是保存网站、程序或代码的文件夹，例如桌面的 `my-website` 文件夹。三个工具可以先后打开同一个项目文件夹。

推荐工作顺序：

1. 用 WorkBuddy 整理需求、客户材料或待办事项。
2. 选择 Codex 或 OpenCode 其中一个修改项目代码。
3. 修改完成后，运行测试或打开网站确认结果。
4. 再用 WorkBuddy 整理修改说明、发布内容或交付清单。

<Warning>
  不要同时让 Codex 和 OpenCode 修改同一个文件。完成一个工具的任务后，先检查并保存文件，再关闭该工具或停止任务，然后再使用另一个工具。
</Warning>

## 什么时候使用 OpenCode

需要用 Xcompute 模型修改代码、在国内网络环境下进行代码任务，或者希望由 Xcompute API 计费时，请使用 [OpenCode 代码任务安装与配置](/opencode-install)。

OpenCode 桌面端和 Codex 都可以打开同一个项目文件夹。打开文件夹前，确认没有未保存的改动。

## 常见问题

### 我有 Codex 订阅，还需要 API Key 吗？

只使用 Codex 订阅时不需要。只有使用 OpenCode 调用 Xcompute 时，才需要 Xcompute API Key。

### 我能让 WorkBuddy 修改代码吗？

WorkBuddy 适合需求整理、资料处理和日常内容。代码修改优先使用 OpenCode 或 Codex。

### 为什么打开后看不到我的项目？

在工具中选择 **打开文件夹** 或 **Open Folder**，然后选择实际保存代码的项目文件夹。不要选择单个文件，也不要选择下载目录中的压缩包。
