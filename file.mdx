## 1. 创建 API Key

打开 [API Key 管理页面](https://xcompute.us/keys)，创建并复制密钥。

<Warning>
  API Key 只放在服务端或本地配置中。不要提交到 GitHub、发送到聊天群或写入浏览器前端。
</Warning>

## 2. 选择入口

| 需求 | 入口 |
| --- | --- |
| 调用文本或图像 API | [API 总览](/api-reference/overview) |
| 修改网站或程序代码 | [OpenCode 配置](/opencode-install) |
| 处理邮件、文档和表格 | [WorkBuddy](/workbuddy) |
| 已有 Codex 官方订阅 | [Codex 协作](/codex-cli-app) |

## 3. 测试文本接口

接口地址统一使用 `https://xcompute.us/v1`。将 `YOUR_API_KEY` 换成自己的密钥，并使用[模型目录](/xcompute-models)中的模型 ID。

```bash
curl https://xcompute.us/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.6-sol",
    "messages": [{"role": "user", "content": "你好，请用一句话介绍你自己。"}]
  }'
```

返回 JSON 即表示请求成功。完整参数见[文本对话](/api-reference/text/chat-completions)。
