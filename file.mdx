Xcompute 当前提供两类能力：文本生成模型与 GPT Image 2.5 图像生成。先创建 API Key，再选择适合你的工具。

## 先选择工具

| 目标 | 推荐入口 |
| --- | --- |
| 写邮件、整理资料、处理表格等日常工作 | [WorkBuddy 日常任务入门](/workbuddy) |
| 修改网站、程序或项目代码 | [OpenCode 安装与配置](/opencode-install) |
| 已有 Codex 官方订阅 | [Codex 订阅与项目协作](/codex-cli-app) |
| 自己开发程序并调用接口 | [通用对话接口](/api-reference/texts/general/new-chat-completions) |
| 生成图片 | [GPT Image 2.5 同步图像生成](/api-reference/images/gpt-image-2/generation) |

## 创建 API Key

1. 打开 [Xcompute API Key 管理](https://xcompute.us/keys)。
2. 点击 **创建新密钥**。
3. 复制生成的 API Key，并保存在安全位置。

<Warning>
  API Key 相当于账户密码。不要发到聊天群、截图、提交到 GitHub，也不要粘贴到不可信的软件或网页。
</Warning>

## 接口地址

国内网络推荐使用 `https://intl.dualseason.com/v1`。Xcompute 主入口是 `https://xcompute.us/v1`。两个地址都必须保留末尾的 `/v1`。

## 快速测试文本生成

将 `YOUR_API_KEY` 替换为自己的 API Key，然后在终端执行：

```bash
curl https://intl.dualseason.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.6-sol",
    "messages": [{"role": "user", "content": "你好，请用一句话介绍你自己。"}]
  }'
```

返回 JSON 内容表示连接成功。模型名称以 [模型广场](https://xcompute.us/models) 当前显示的文本模型为准。

## 当前可用能力

| 能力 | 模型或接口 |
| --- | --- |
| 文本生成 | `POST /v1/chat/completions` |
| 同步图像生成 | `gpt-image-2.5` |
| 异步图像生成 | `gpt-image-2.5-async` |
