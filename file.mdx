## 创建 Xcompute API Key

只有调用 Xcompute 中转模型时才需要 API Key。打开 [API Key 管理页面](https://xcompute.us/keys)，创建并复制密钥。

<Warning>
  API Key 只放在服务端或本地配置中。不要提交到 GitHub、发送到聊天群或写入浏览器前端。
</Warning>

## 第一次请求

接口地址统一使用 `https://xcompute.us/v1`。将 `YOUR_API_KEY` 换成自己的密钥，并使用[模型目录](/xcompute-models)中的模型 ID。

```bash
curl https://xcompute.us/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-5.6-sol",
    "messages": [{"role": "user", "content": "你好，请用一句话介绍你自己。"}]
  }'
```

返回 JSON 即表示请求成功。详细参数见[文本对话](/api-reference/text/chat-completions)。

## 使用原则

- 简单任务优先使用工具自带的免费 AI。
- 复杂任务再使用 Xcompute 中转模型，避免为不需要的能力付费。
- 先拆分任务、减少重复上下文、只发送必要文件。
- 每次修改后检查 diff 和测试结果，合理使用 AI 也能减少 Token 消耗。
