## 打开命令行

<Tabs>
  <Tab title="Windows">
    在开始菜单搜索并打开 **PowerShell**。
  </Tab>
  <Tab title="macOS">
    按 `Command + 空格`，搜索并打开“终端”。
  </Tab>
  <Tab title="Linux">
    按 `Ctrl + Alt + T` 打开 Terminal。
  </Tab>
</Tabs>

教程中的命令只能粘贴到 PowerShell 或终端，不要粘贴到浏览器地址栏。

## 检查 Node.js

```bash
node -v
npm -v
```

如果两条命令都显示版本号，可以继续 [OpenCode 配置](/opencode-install)。没有安装时，从 [Node.js 官方下载页面](https://nodejs.org/en/download)安装 LTS 版本。

## 执行命令

1. 只复制代码框中的命令。
2. 粘贴到 PowerShell 或终端。
3. 按 Enter，等待上一条命令结束后再继续。

停止卡住的命令使用 `Ctrl+C`。Windows 复制和粘贴使用 `Ctrl+C` / `Ctrl+V`；macOS 使用 `Command+C` / `Command+V`；Linux 终端粘贴使用 `Ctrl+Shift+V`。

## 配置文件

OpenCode 配置文件位置：

- Windows：`%USERPROFILE%\\.config\\opencode\\opencode.json`
- macOS / Linux：`~/.config/opencode/opencode.json`

JSON 必须使用英文双引号，最后一项不能多逗号。修改后完全退出并重新打开 OpenCode。

<Warning>
  API Key 不要上传到 GitHub、放进项目目录或出现在截图中。泄露后立即删除并重新创建。
</Warning>
